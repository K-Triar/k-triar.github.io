PHILOSOPHY

企業理念

瑠璃からつながる、世界がつながる。

Kトライア瑠璃交通は、瑠璃国内の移動を支える鉄道インフラを安全かつ確実に走らせることから始まりました。

日々の運行の確かさをすべての土台としながら、私たちは一歩先を見据えています。それは、世界中の鉄道情報と運行のしくみをオープンにし、人と街、そして多様な路線同士をなめらかにつなぐことです。

地域の暮らしに欠かせない身近な足であり続けるとともに、情報と技術の力で鉄道の可能性を世界へと広げていきます。

EFFORTS

取り組み

01 安全と確実さの追求

目的地へ、安全かつ確実に。日々の運行の確かさは、利用者の皆様との最も大切な約束です。TrainCarts を活用した自動進路制御や駅設備の適正な整備により、安心で快適な輸送体制を維持しています。

02 情報をひらく（REWIS の開発・運用）

路線図や停車駅、乗換案内、日々の運行状況といった鉄道情報は、だれもが等しく受け取れるべき社会インフラです。自社線にとどまらず、世界中の鉄道網のデータを集約・公開する「全世界鉄道情報システム（REWIS）」を開発・運営し、誰もが自由に移動を調べられる環境を整えています。

03 しくみを共有する（運行規格の標準化と支援ツール）

培ってきた運行ノウハウや技術は、一社の中に閉じ込めるのではなく、共通の規格として広く共有します。TrainCarts 運行方式（KT式「経路コード方式」）の仕様を文書化して公開するとともに、設定支援ツール「KT式 TCビルダー」を提供し、他の鉄道事業者との相互乗り入れや路線構築を支えています。

PROFILE

会社概要

組織名 Kトライア瑠璃交通（英称: K-Triar Luli Transport）
所属グループ Kトライア交通グループ（Kトライアホールディングス傘下）
事業内容 1. 瑠璃国内および近隣地域における鉄軌道事業の運営
2. 全世界鉄道情報システム（REWIS）の企画・開発・運営
3. TrainCarts 運行方式（KT式）の規格策定・開発、および設定支援ツール（TCビルダー）の提供
運営路線 瑠璃本線、地下鉄中央線、地下鉄交易所線、貿易港線、瑠璃新幹線
主要拠点 瑠璃中央（本社機能）
関連組織 Kトライアネザー交通、Kトライア東北交通
活動環境 3DS半分こするくらい仲良しクラフト（DSクラフト）
公式アカウント GitHub (@K-Triar)

沿革

2022年12月 DSクラフトへの移行に伴い、鉄道事業団より瑠璃線・貿易港線をKトライアホールディングスへ移管
2023年9月 Kトライア交通グループ発足に伴い、Kトライア瑠璃交通として事業開始。瑠璃島地下鉄より地下鉄中央線・地下鉄交易所線を譲渡され、瑠璃国内の一体的な運行体制を確立
2026年4月 全世界鉄道情報システム「REWIS」の提供を開始
2026年9月 KT式 TrainCarts 設定支援ツール「TCビルダー」を公開
2026年10月 Kトライア瑠璃交通 公式ウェブサイトを公開
