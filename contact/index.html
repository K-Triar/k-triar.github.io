お問い合わせ

Kトライア瑠璃交通および提供サービス（REWIS、TCビルダー）に関するお問い合わせ、ご意見、不具合報告は、以下の窓口にて受け付けています。

お問い合わせの内容に応じて、適切な窓口をご利用ください。

主な窓口

窓口 主な受付内容 リンク・連絡方法
DSクラフト公式 Discord ゲーム内の運行・設備に関するご連絡、ご意見、REWISへの新規路線登録申請 サーバー内「Kトライア瑠璃交通」関連チャンネル、または担当者へのダイレクトメッセージ
GitHub Issues Webシステムやツールの不具合報告、機能要望、データ修正依頼 各リポジトリの Issues（下記参照）

GitHub でのお問い合わせ先（リポジトリ別）

  • 公式サイトに関する問題（表示崩れ、誤字など）
    K-Triar/k-triar.github.io Issues
  • REWIS に関する問題（乗換案内、路線図、エディタ、データ誤りなど）
    K-Triar/rewis Issues
  • KT式 TCビルダーに関する問題（計算ロジック、看板出力など）
    K-Triar/tc-builder Issues

内容別のご案内

鉄道事業者様向け（REWIS への路線データ登録・更新）
DSクラフト内で鉄道を運営されている事業者様で、REWISへの路線データ新規掲載や事業者向けエディタ用アカウントの発行をご希望の場合は、DiscordにてKトライア瑠璃交通担当者までお申し出ください。

ゲーム内の運行・設備に関する異常
線路・駅設備の破損や列車のスタックなど、ゲーム内の運行に支障が生じている場合は、Discordまたはゲーム内チャットにて速やかにお知らせください。

ご注意事項

  • 回答には日数をいただく場合があります。
  • DSクラフトのサーバールールおよびコミュニティ規約に反する内容や、個別のゲーム内トラブル（規約違反行為の通報等）については、サーバー運営チームの所定の窓口へご相談ください。
